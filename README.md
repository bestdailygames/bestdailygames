# Best Daily Games

A community-curated list of daily word games, trivia, geography, logic, music and movie puzzles. Daily games offer a fresh challenge each day, often shared by everyone playing.

Browse, save favorites and find researched guides at **[bestdaily.games](https://bestdaily.games/)**. This repository contains the directory and contribution docs; the website’s application code is maintained separately.

## Contributing

Help discover new games and keep existing entries accurate. **[Suggest a game](https://github.com/bestdailygames/bestdailygames/issues/new?template=game-suggestion.yml)**, [report a correction](https://github.com/bestdailygames/bestdailygames/issues/new?template=report-listing.yml), or edit this README and open a pull request.

One game per Issue. Use the form, or follow this format:

```text
Title: [Game suggestion] Game name
Original play URL:
Category and one-sentence gameplay description:
Daily mode / rules source:
Account, payment, language or device restrictions:
Your relationship to the game:
```

- **Add:** suggest the original publisher’s play URL for review. Published game names link directly to the original.
- **Fix:** include the affected entry, what changed and a supporting source.
- **Review:** help check [open suggestions](https://github.com/bestdailygames/bestdailygames/issues); comment first to coordinate larger edits.

Players and creators are welcome. Keep descriptions factual and spoiler-free; disclose your connection to a game. Maintainers review submissions before inclusion. No payment or reciprocal link is required. See [CONTRIBUTING.md](CONTRIBUTING.md) for the checklist.

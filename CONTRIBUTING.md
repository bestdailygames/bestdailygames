# Contributing to Best Daily Games

Thank you for helping people discover their next daily puzzle.

## Suggest a game

Use the [game suggestion form](https://github.com/bestdailygames/bestdailygames/issues/new?template=game-suggestion.yml). One game per issue, please. Search the README and existing issues first.

Provide the original HTTPS play URL, category, one-sentence gameplay description and publisher evidence of a daily mode. Note language, account requirements, payments, mobile limitations and your connection to the game. We welcome creators submitting their own work; please disclose that relationship.

We look for a usable daily challenge, clear instructions and a distinctive experience. Avoid mirrors with unclear provenance, affiliate/referral links, misleading free-play claims, spoilers and descriptions copied from another directory. No payment or reciprocal link is required. Review and inclusion are editorial decisions.

## Correct an entry

Use the [listing correction form](https://github.com/bestdailygames/bestdailygames/issues/new?template=report-listing.yml). Include the affected game and URL, what changed and a publisher source or reproducible observation. A temporarily blocked request alone does not prove a game is permanently offline.

## Propose a README edit

1. Fork this public directory and edit `README.md`.
2. Add the game alphabetically in the best fitting category, using one primary category.
3. Link the game name to the original publisher and write one specific, factual sentence.
4. Add a matching bestdaily.games guide only if that page is already live; otherwise use `—` in the Guide column. A website guide is not a prerequisite for suggesting a game.
5. Put the actual editorial review date in `YYYY-MM-DD` format. Do not advance dates for unchanged or unchecked entries.
6. Update the listing count and `CHANGELOG.md` for substantive changes.
7. In the pull request, include your sources, access notes, checks performed and any relationship to the game.

Keep paused games and companion platforms in their separate sections. Do not claim a game is official, free, unlimited, account-free or mobile-friendly without evidence. Do not include website source code, credentials, private analytics or personal information.

## Maintainer review

Before merging, verify the original destination, gameplay description, category, daily schedule where documented, relevant access conditions and any live guide link. Record a real review date and describe substantive changes in the changelog. Preserve publisher credit and move paused entries to the archive section when supported by the publisher.

This repository publishes documentation and listing assets. It does not distribute the website application or third-party game code. For private support, email [support@bestdaily.games](mailto:support@bestdaily.games).

# Contributing to Best Daily Games

Players, creators and reviewers are welcome. No application coding is needed.

## Suggest a game

Search the README and existing issues first. Open the [game suggestion form](https://github.com/bestdailygames/bestdailygames/issues/new?template=game-suggestion.yml), one game per Issue. Include:

- Name and original HTTPS play URL.
- Category and one factual, spoiler-free sentence about the gameplay.
- Publisher rules or help page showing its daily mode.
- Account, payment, language and device restrictions, or “unknown” if unchecked.
- Your connection to the game, including creator or publisher relationships.

Use original destinations without referral links. A suggestion is reviewed before inclusion; no payment or reciprocal link is required.

## Fix or review a listing

Use the [correction form](https://github.com/bestdailygames/bestdailygames/issues/new?template=report-listing.yml) with the affected entry, the correction and evidence. Check open issues and PRs; comment before starting a larger edit to avoid duplication.

## Open a pull request

Edit `README.md` using GitHub’s pencil icon, or fork and submit a PR.

- Add the entry alphabetically in one suitable category.
- Link the game name to its live `https://bestdaily.games/games/<slug>/` page and keep the description to one sentence.
- Put the original publisher URL and rules source in the Issue or PR for verification. If no Daily Games page exists yet, suggest the game through an Issue first.
- Keep puzzle platforms and paused games in their own sections.
- Include publisher sources, checks performed, actual review date and your relationship in the PR.
- Update the count and `CHANGELOG.md` for substantive changes. Never advance dates without a completed review.

Maintainers check accuracy, usability and access conditions before merging. Contributor credit remains in the PR and commit history. This directory publishes documentation and brand artwork; leave out website source code, credentials and private information.

Private support: [support@bestdaily.games](mailto:support@bestdaily.games).
